# 原始漫游基线与蒸馏诊断（2026-11-13）

## 已撤回原片附色

用户在实际播放器发现灯边黄绿色污染、雾感及清晰度退化。`77d99ab` 的
逐机位附色功能已通过 `af780a5` 整体回退；不再把全图 MAE/灰度 SSIM
改善称为画质验收通过。原非颜色字段确实没变，但这不保证改色后无局部退化。
颜色优化补偿渲染/投影误差是可能机制，尚未验证黄边的唯一原因或有效修复。

原片附色三个已部署场景标记为 retired。播放器阻止加载这些模型，并提供
原始漫游链接；模型和旧报告只留作本地诊断，不继续推荐下载。

固定代码基线标签：`baseline-native-tour-20261113`，指向 `6f28b9f`。
六份原始 PLY 的 SHA256 已全部与原始包清单核对一致。

- 原始 49% 漫游：`/native-tour-room.html?scene=native-source-six-v1&range=0.49`
- 极短融合过渡：`/native-tour-room.html?scene=native-source-six-v1&fused=tour-appearance-six-v1`

49% 是接近 50% 的工程配置；精确 50% 的最近机位选择会变为硬切换。
默认的停下清晰优先涉及时间状态，静态 PLY 无法保存这一播放状态。
蒸馏试验继续使用固定 49% 空间权重，不使用撤回的附色模型作教师。

## 先分离采样误差与蒸馏误差

`tests/capture_native_teacher.mjs` 从任务专用 CDP 浏览器捕获实际原始模型
画面及局部/世界相机矩阵：机位 1、4，各水平、上、下 90°，上方 45°，
以及向邻机位移动 10% 后向下，共 10 幅 768×768 图像。全部确认原始来源
权重为 1、融合模型权重为 0、空间范围为 49%。这是有限视角诊断，不是全屋验收。

`scene_fusion/native_teacher_audit.py` 用同一相机对比：

| 对比 | 平均 RGB MAE（0–1） |
| --- | ---: |
| 浏览器原始 PLY vs 离屏原坐标 PLY | 0.0031362 |
| 离屏原坐标 vs 变换到公共坐标 | 0.000000205 |
| 浏览器原始 PLY vs 离屏教师 | 0.0031362 |
| 浏览器原始 PLY vs 8 位颜色/透明度教师 | 0.0026183 |
| 浏览器原始 PLY vs 现有单一 PLY | 0.0075994 |
| 离屏教师 vs 现有单一 PLY | 0.0066972 |

这些误差不是可相加的因果分解。结果支持：此批视角的坐标变换正常；
量化能解释部分渲染器差异；教师接近原始画面，但学生仍丢失细节。
不能据此声称所有位置、所有场景的配准都正确，也没有证明一个唯一根因。

代码中的可验证差异：`gaussian.js` 默认相机 FOV 为 50°，原蒸馏主要使用
90°；PLY 颜色/透明度转成 8 位；网页 3D 高斯片元在马氏距离平方 > 8 时
截断。离屏渲染走现有 gsplat 实现。仅调整量化不足以消除差异。

目视同相机四栏图（原始浏览器/离屏教师/单一模型/放大误差），桌面细线和
椅脚轮廓的损失主要出现在单一模型一栏。原始模型自身仍有少量地面斑驳。

## 已执行的窄视角对照，不发布

固定原始教师、49% 权重、现有 `tour-appearance-six-v1` 初始化，分别运行
450 步、768/1024 分辨率的固定几何外观训练。控制组沿用原数据；另一组用
`tour_detail_views.py` 自动为所有机位及近机位训练视点增加 50° 监督，60°
留作检查。没有手动指定物体或房间区域，未改六份原始 PLY。

| 模型 | 浏览器参考平均 MAE | 最差 32×32 图块 MAE |
| --- | ---: | ---: |
| 原有单一 PLY | 0.0075994 | 0.1470465 |
| 同步数普通续训 | 0.0082548 | 0.1465676 |
| 增加窄视角训练 | 0.0084679 | 0.1465986 |

两候选平均退化，局部最坏图块没有实质改善，均拒绝，不导出预览、不替换基线。
这只是短程消融，不能证明多视角训练永远无效；它否定了“补上 50° 就已修好”的
判断。原有全图指标不足的问题也没有因此自动解决。

后续优先事项：用相同相机核验教师；以局部彩边、纹理对比度和轮廓误差验收；
再隔离测试细节区域的高斯覆盖大小、密度和透明度，并检查跨机位监督冲突。
所有候选必须与原始漫游及已接受单一模型比较，退化时保持基线。

公开数值与验证状态见 `experiments/2026-11-13-native-rollback`。
