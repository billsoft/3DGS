# 通用场景运行器

`run-scene.ps1` 是当前推荐入口。拍摄数量由输入自动确定，无需修改相机编号、配准边、分区数量或播放器按钮。算法从本次原始输入重新计算，不借用旧会议室的标定、collider、网格或物体模板。

## 本机使用

本机已配置 `scene_fusion/settings.local.json`。在仓库目录运行：

```powershell
.\run-scene.ps1 -Inputs 'C:\Users\bills\Pictures\六组_去三脚架_7680x3840'
```

以后换场景只替换 `-Inputs`。默认建立新的输出目录，结束时打印预览地址，模型位于该目录 `final/fused.ply`。原始输入不会被覆盖。该入口运行于原生 Windows，不使用 WSL。

仅验证输入：

```powershell
.\run-scene.ps1 -Inputs 'D:\新房间' -OutputDirectory 'four-room/scenes/my-room' -Check
```

运行或恢复同一输出，使用同样的参数并加 `-Resume`。只选择部分机位可加 `-Stations @('1','2','4')`；这是原文件名，不是内部编号。

```powershell
.\run-scene.ps1 -Inputs 'D:\新房间' -OutputDirectory 'four-room/scenes/my-room' -Resume
```

新机器先复制 `scene_fusion/settings.example.json` 为 `settings.local.json`，配置 CPU Python、GPU Python 和可选 HTTP 服务目录；GPU 环境及 `run-refit-gpu.ps1` 的 VS/CUDA 路径也须配置。入口不会自动安装 CUDA 或启动 HTTP 服务。配置文件不提交到 Git。

## 输入范围

- 至少两组有重叠、能建立连通匹配图的全景图与 Gaussian PLY；不限于四组或六组。每个 PLY 和对应照片同名，例如 `机位 A.ply` / `机位 A.png`。支持 JPG、JPEG、PNG，以及历史的 `名称_7680.jpg` 配对。一个 PLY 存在多个候选照片会明确报错。
- 全景图为完整 2:1 等距柱状投影，不要求 EXIF。可以使用不同分辨率，但不能把普通透视照片当全景输入。图片和 PLY 必须确实对应同一来源。
- 支持 ASCII、大小端二进制 PLY；按属性名称读取，可有法线、重排字段、全零高阶 SH 属性。必须包含位置、DC 颜色、透明度、三轴 log-scale、四元数。非零高阶 SH 明确拒绝，防止静默丢失外观；普通点云或 mesh PLY 不符合输入契约。
- 中文文件名映射为稳定的安全内部编号。原名称用于播放器显示。尺度按每个模型的稳健半径归一化，避免厘米、米或不同导出尺度影响固定阈值；结果没有可保证的真实米制尺度。
- 新内容、数量或选择集合使用新输出目录；输入 SHA-256 不同会拒绝复用旧场景。

## 通用流程与防退化

输入校验 → 原片与自身 PLY 标定 → 像素贡献可见性筛选 → 全部来源对的匹配及 Sim(3) 初始化 → 球面多视图束调整 → 尺度更新 → 可见性约束的负责区域 → 照片联合拟合 → 原始完整 PLY 对照 → 质量闸门 → 导出与发布。

相机规范固定首相机及较长初始化基线，避免默认第一、第二个机位过近。不连通匹配、低证据标定及无有效三角化轨迹会报错，不能用猜测的位置继续融合。`-DepthWarp` 为可选、有图像约束的径向局部变形，默认关闭，不是任何场景都能受益。

每个阶段的参数、代码版本和输出哈希构成断点；文件损坏、代码或参数变化会使相应结果失效。各来源的昂贵标定和可见性缓存以原片、PLY、相关代码哈希标识，并校验每个缓存文件。状态在 `run-state.json`，逐阶段日志在 `logs/`。失败后输出保留，修复原因后可继续运行。

发布前检查留出轨迹的配准误差、平均及逐方向来源 SSIM、完整原始 PLY 固定掩码的覆盖损失，并验证评估报告对应当前候选的哈希。失败候选保留供排查，但不导出发布为成功结果。阈值见 `scene_fusion/quality.py`。质量闸门是回归检查，不是对未拍区域和所有中点几何的保证。

## 计算与效果边界

机位数量没有写死，但匹配对数为 N(N−1)/2，GPU 开销取决于高斯数量与分辨率；不承诺无限数量可在当前显存内完成。单组没有多视图融合意义，目前入口要求至少两组。

所有来源都看不到的表面没有实拍约束。反光、透明物体、白墙、重复纹理、动态物体以及每份生成 PLY 不一致的深度仍可能造成失败或残留重影。来源照片参与拟合，来源 SSIM 不等于新视点准确率。此重构解决数量、文件名、尺度、缓存和流水线的通用性，不把生成模型变成精密扫描仪。
