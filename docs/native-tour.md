# 扩大原始范围与机位间连续漫游

入口：`/native-tour-room.html?scene=native-source-six-v1`。沿用原始机位包 `native.json`，不重新生成或修改任何 PLY。机位数量、坐标、模型与路线均来自元数据。

上一版的纯原始区域只有最近机位间距的 8%，24% 后完全切回旧融合模型。这会让用户一离开拍摄点就看到旧融合模型的缺陷。

新版默认沿相邻机位连线，在前 38% 完全使用起点原始 PLY，38%–62% 直接过渡到终点原始 PLY，后 38% 完全使用终点原始 PLY；中间不加载融合模型。页面提供 30%、38%、44% 三个纯原始范围选项。更大的纯原始区域意味着更短的过渡带，并不证明原始模型在更大范围内的几何一定正确。

两个来源分别保留原始坐标、形状、透明度与颜色，相机通过相似变换的逆变换进入各自坐标系。完整渲染后才混合图像，不能把图像权重直接乘到高斯点透明度上。多层画面的 CSS 透明度按累积权重换算，避免黑色背景漏出和混合权重计算错误。

自由移动按照最近两个机位的归一化距离差决定权重。对机位组合改变和预载完成时的权重变化进行时间平滑，避免三机位交界处突然跳变。拍摄光心强制恢复对应原始模型的 100% 权重。

默认勾选“停下时清晰优先”：停止平移约 180ms 后逐渐转为一份原始模型。距离近似相等时保留当前主来源，避免反复切换；原地转头不会重新启动双模型混合。该行为用于避免驻足时保留两个错误对齐轮廓，不是几何修复。取消勾选可对照持续渐变的画面。

点击机位时沿元数据中的邻接图选择最短路径，分段平滑移动，同时预载下一个机位。这个路线不是碰撞检测，也不能保证元数据的每条边都避开障碍。鼠标拖动或 W/A/S/D、Q/E 可中断移动。

原始文件按需加载，通常只需要两个模型渲染；闲置来源采用缓存淘汰，以避免每次都加载 N 份模型。三机位交界的短暂混合可能同时出现三个来源。最多保留四个常驻来源，正在使用/加载或路线需要的来源可能暂时超过缓存目标。

验证包括：扩大后的纯原始范围、权重连续性、图像混合计算、邻接路径、各机位与单独原始 PLY 的同视点对照、实际浏览器机位移动和原地转头。过渡画面需要另外目视检查，端点保真不能证明中间没有双影。

本版提供看房式运动与原始模型之间的渐变，不包含稠密光流形变，也不是新的静态融合 PLY。独立生成的模型若局部结构不一致，过渡中仍可能双影；远离拍摄路线可能暴露原始模型的背面或错误深度。
