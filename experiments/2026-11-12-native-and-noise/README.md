# 原机位保真与灰面噪斑排查

本轮交付原始 PLY 保真多模型播放器；没有将颜色实验替换为新的正式融合基线。

## 已通过的原机位播放

- 六份源 PLY 的 SHA-256 与标定输入及发布副本逐字节一致，共 3,051,998 个高斯。
- 六机位 × 六方向检查通过；各拍摄点只有对应来源可见，原始层权重为 1，世界坐标及局部相机位置符合相似变换。
- 六个中点回到已有融合模型。真实鼠标拖动原地转头的位置误差为零。
- 18 张 1280×900 同视点图，与独立加载一份原始 PLY 的渲染对照：最大平均绝对像素误差 0.01984/255；最差一图中 RGB 任一通道误差超过 5/255 的像素占 0.0442%。这不是逐像素完全一致，也不是与原片一样清晰。细微排序差异仍存在。

## 噪斑根因证据

照片灰色不意味着构成它的每个高斯都是灰色。像素是按前后遮挡关系进行的透明度合成；基础颜色、SH 视角项、形状、透明度共同决定结果。相同灰色和灰色背景的正确混合不可能产生蓝紫色。若出现彩斑，必有非中性色贡献或渲染计算偏差；仅覆盖不足可以产生深浅斑，却不能凭空产生新的色相。

本轮确认：

1. 未融合的单份原始 PLY 在标定视点也有细小斑点，照片更干净。不能把全部源噪点归因于拼接。
2. 将浏览器相机矩阵、宽屏比例、投影矩阵精确复制给离线渲染器后，同样出现脏斑。旧版只用六个固定 90° 方形视向检查，漏掉了其他投影方向/宽视野中的退化。
3. 同一宽屏相机下，旧模型天花板/地面的浏览器对原片 MAE 为 0.01787/0.02200；离线为 0.01824/0.02098。浏览器与离线本身的 MAE 为 0.00540/0.00396，仍有实现差异，但主要脏斑在两者中都出现。
4. 在多视图支持且目标近灰的 172,387 个完整一致颜色候选中，约 42.1% 的基础 RGB 通道跨度大于 0.05，约 99.1% 存在非零高阶 SH。这证明潜在高斯颜色不等于照片中最终看到的均匀灰面。此统计不是逐像素光学贡献追踪，不能据此认定每个候选都是错误点。

固定相机中心转头不会改变每个高斯的 SH 观察方向（它由相机到高斯的方向决定）；投影覆盖和排序可能改变。当前证据支持存在投影相关的外观补偿/过拟合，尚未将每个斑点归因到具体几何或透明度错误。

## 两项可复现实验

`scene_fusion/consensus_color.py` 用原片作为颜色边缘引导，要求至少两个深度支持机位、整个高斯覆盖采样颜色平坦且机位间一致，只修改颜色和 SH，不动几何/透明度。修改 312,456 点后，36 个固定方向的 SSIM 全部下降：平均 0.95968 → 0.95419，MAE 0.00933 → 0.01087。目视出现明暗斑，拒绝发布。高斯中心的投影颜色不能直接代替该高斯对整片屏幕像素的贡献。

`scene_fusion/orientation_dataset.py` 加入同一光心的随机转头、roll 和 75°–115° 视野，照片直接重投影生成监督，未合成新图。使用 108 个来源投影视图和 18 个原中点约束进行 4,000 步固定几何颜色拟合。

| 检查 | 旧版 | 多投影实验 |
|---|---:|---:|
| 36 个未训练投影视向平均 SSIM | 0.90414 | 0.92429 |
| 以上视向平均 MAE | 0.02061 | 0.01577 |
| 旧 36 个固定方向平均 SSIM | 0.95968 | 0.95549 |
| 旧固定方向平均 MAE | 0.00933 | 0.01017 |
| 用户宽屏上视向离线 MAE | 0.01824 | 0.01160 |
| 用户宽屏下视向离线 MAE | 0.02098 | 0.01537 |

35/36 个未训练投影视向改善，但 32/36 个旧固定方向退步，最坏 SSIM 下降 0.01843；严格原始 PLY 局部保真检查 31/36 方向未通过。没有新增低透明度孔洞。该实验说明补充投影监督有用，但不能认定已经消除几何错误或所有斑点；未作为默认融合模型上线。未训练投影视向仍来自同批照片，不能当作独立新视点真值。

## 后续应处理什么

需要以实际像素贡献、遮挡和表面邻接建立约束，避免跨层颜色补偿；颜色/几何滤波后必须重新检查原光心的整片球面和中间视点。可以试表面法线与深度门控的双边平滑，但不能用普通空间 KNN 把桌面、椅子和地面跨层平均。

- [Mip-Splatting](https://github.com/autonomousvision/mip-splatting)：采样频率与投影滤波约束，解决特定尺度/采样伪影，不等于去掉错误浮层。
- [2DGS](https://github.com/hbb1/2d-gaussian-splatting)：表面表示、深度失真与法线一致性约束，可用于重新建立更一致的几何。
- [Bilateral Guided Radiance Field Processing](https://bilarfpro.github.io/)：双边网格处理照片外观差异，不是任意 PLY 的几何去噪器。

直接将污染的融合高斯转成 mesh 可能固化错误；经过验证的公共表面再做可见性贴图才有意义。原始 PLY 保真播放先确保机位内不再额外受融合损伤，中间区域的真实几何一致性仍待解决。
