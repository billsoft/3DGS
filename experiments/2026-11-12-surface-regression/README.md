# 六机位中间视点退化：候选未通过

结论：通用输入和自动运行已验证，但当前通用融合模型没有达到旧四机位房间基线的中间视点质量。本次保守候选被自动质量检查和目视检查同时拒绝，没有导出发布为新的可用结果。

## 旧四机位与新流程的差异

旧 `2026-11-11-coverage-guard/fusion.json` 记录 328542 个三角形、3166125 个高斯，方法为经过验证的稠密光流几何修正、公共表面接缝图分区和窄带羽化。其初始化记录明确包含此前电视、地球仪和桌面的几何拟合。后续 `shape-free` 候选固定高斯中心，仅拟合颜色、尺度、旋转和透明度。

新通用入口从独立生成的 PLY 开始，直接做可见性分区、照片拟合，没有继承上述公共表面或房间专用初始化。不能把两者差异解释为机位数量从四变六，也不能由新入口跑通就推断重建质量已通用。

同一批六机位原片的四机位子集也存在电视分层。将该子集相机中心对齐到六机位公共坐标后，RMS 为 0.02107 个归一化单位；此前带深度修正六机位结果的相机中心对齐 RMS 为 0.00265。比较用于目视诊断，不是独立真值的逐像素评测。旧四机位为另一批输入，不将其不同拍摄位置画面冒充同视点对照。

## 已修代码缺陷

邻接图原来固定取高斯旋转矩阵第一个轴作为表面法线，但原始 PLY 不保证该轴是最短轴。改为按最小 log-scale 选择旋转轴；新增等价协方差轴排列不应改变法线的回归测试，24 项 CPU 测试通过。流水线代码哈希纳入新几何函数，防止断点恢复误用旧邻接结果。

新增可选 `--preserve-color-differences` 仅用于试验，将邻接惩罚从邻点颜色差改为颜色差的改变量。默认关闭；本次组合试验失败，不能独立宣称该选项提高画质。

## 被拒绝候选

使用原六机位标定与相机轨迹，恢复照片轨迹约束的径向深度修正，刷新深度，重新分区并构建正确法线的邻接图。训练 2800 步 512 + 1400 步 1024，固定高斯中心、旋转和透明度，只调整颜色及有界尺度；图正则 0.8、边缘项 0.3，启用颜色差保护。

1024 完整原始 PLY 掩码：原始平均 SSIM 0.95173，候选 0.91967；平均及部分方向退化超出阈值。新增低覆盖像素为零，说明“无新增洞”并不能证明重影或模糊已解决。目视中间视点电视仍有多层、拖影；未通过，不更新旧四图基线或通用六图预览。

本次是组合试验，不把失败归因到某一个参数。事实支持：稀疏径向深度场、来源分区和保守照片拟合不足以消除当前独立生成几何之间的冲突。下一阶段需要验证通用公共表面及空空间一致性；尚未实现或证明此路线能在任意输入上恢复旧房间基线质量。

`result.json` 保存候选哈希、自动质量结果和人工拒绝结论；原图、模型、截图与实验脚本产物留在本机。
