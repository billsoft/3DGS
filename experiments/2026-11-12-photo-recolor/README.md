# 原图重附色与脏斑诊断

在 `geometry-quads-v1` 的同一份 1464515 点模型上进行独立对照。保留上一版公共平面修复，不覆盖旧基线。不使用墙、灯、门等语义掩码或房间专用坐标。

## 问题与证据

高斯点的颜色不是最终屏幕像素：透明度、覆盖范围、遮挡顺序和其他高斯共同决定渲染结果。当前独立生成几何的深度/遮挡仍不一致，来源相机能拟合较好不代表两个机位之间也正确。直接把原图像素写到高斯中心可能使某些墙面更均匀，但也把高亮扩散到错误的覆盖范围，产生更明显的亮雾。

只恢复原始 PLY 颜色、保持其余参数不动的对照，局部脏斑有变化，但整体来源拟合退化。恢复原始几何参数而保留拟合颜色也会变坏，说明颜色与几何/透明度补偿耦合，不能独立回退一个参数就认为恢复了原始质量。

本轮没有证明曝光差是主要原因，也没有证明单一参数造成所有脏斑。

## 消融试验（512 方形视图，36 个来源方向）

掩码固定为上一版 alpha；平坦区域由原图 11×11 邻域标准差确定，不从候选图像挑选。

| 变体 | 平均 SSIM | 平坦区域 RGB MAE | 结论 |
|---|---:|---:|---|
| 上一版几何修复 | 0.941113 | 0.005951 | 对照 |
| 仅恢复原始 PLY 颜色 | 0.881442 | 0.015429 | 不发布 |
| 按各自来源照片直接重附色 | 0.873586 | 0.015936 | 不发布；部分墙面均匀但灯周围亮雾加重 |
| 原生深度可见性 + 原图平坦区域保护 | 0.921818 | 0.012042 | 不发布；仍有跨区域污染 |

另实现了两倍标准差足迹的照片颜色跨度检查，避免中心落在平坦区域、覆盖范围却跨过明暗边缘的点被直接附色。该分支保留为诊断工具，没有独立证明它优于最终渲染拟合版本。

## 最终颜色对照版

从受可见性和平坦区域保护的原图颜色初值开始，锁定所有几何、尺度、旋转和透明度，通过实际渲染拟合原始照片，只更新颜色。保留初值的中点信任项，2000 步 512 + 1400 步 1024。图颜色平滑项关闭；此前公共平面的 404438 个点颜色受保护。

这是组合试验：同时改变颜色初值、冻结几何和关闭图颜色平滑，不能把全部收益归因于某一项。

1024 同一基线掩码：

| 指标 | 上一版 | 本版 |
|---|---:|---:|
| 平均 SSIM | 0.950351 | 0.951173 |
| 全图 RGB MAE | 0.011110 | 0.010638 |
| 原图平坦区域 RGB MAE | 0.006218 | 0.005803 |
| 平坦区域高通残差 | 0.00274593 | 0.00274514 |

平坦区域平均颜色误差下降约 6.7%，高频细噪指标几乎没有变化。36 个来源方向中 31 个 SSIM 提升，最差方向下降 0.001206。不能将这一小幅改进描述为整房间去雾或几何噪点清除。

完整原始 PLY 固定掩码审计：原始 PLY 平均 SSIM 0.951726，候选 0.952327；37264106 个原生高覆盖像素没有新增低透明度孔洞。中间视点仍无独立照片真值，进行了目视对照。

真实训练产物验证：位置、log-scale、opacity 逐值一致；四元数保存归一化导致的旋转矩阵最大误差 7.82e-8；受保护颜色 SH 最大误差 1.19e-7。候选 SHA256：`4b27020e1d90fa3c9b31a7c15c529baca1cb3e456f30961d723bd587da31be0b`。PLY 回读逐值一致。

35 项 Python 测试通过，覆盖全景极点和环绕、相机变换、遮挡/纹理拒绝、中心像素看不到但足迹跨过的边缘。另检查真实训练输出的几何和受保护外观不变。实际网页验证等待完整排序后截图。

## 使用与限制

`scene_fusion/photo_recolor.py` 接受场景清单、融合模型、逐点来源编号及可选保护掩码；不限于四或六机位。来源编号必须与模型点顺序一致。`--restore-from` 是消融工具，只有逐点身份完全匹配时才允许恢复历史参数。

```powershell
python scene_fusion/photo_recolor.py --scene <scene> --model <model.npy> --owners <source.npy> --protected <protected.npy> --out <independent-output>
```

训练器新增 `--protected-appearance`，可在重拟合时保留已接受区域的颜色。本次候选通过现有来源回归门槛，但沿用上一版的几何限制；不据此升级为通用完整重建结果。

灯边、地面纹理破碎、支架及其他漂浮层仍需几何和遮挡一致性处理。原图颜色不能恢复没有被观察到的表面，也不能让错位的两层变成一个正确表面。

方法依据：[gsplat alpha compositing](https://docs.gsplat.studio/main/apis/utils.html)、[gsplat 1.5.3 rasterization](https://docs.gsplat.studio/versions/1.5.3/apis/rasterization.html)、[原始 3DGS 项目](https://github.com/graphdeco-inria/gaussian-splatting)。本轮未宣称复现其深度正则或曝光补偿。
