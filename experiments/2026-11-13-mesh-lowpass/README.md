# 低频几何与照片分区对照

已接受基线保持 `baseline-mesh-guide-20261113`，14 个产物 SHA-256 未变。
本目录保存两个独立候选的重建参数、数值焊接、浏览器检查、射线检查、
局部平面法线以及原照片外观误差。照片和模型本体不提交公共仓库。

| 版本 | 面数 | 开放边 | 非流形边 | 棚顶照片 MAE |
|---|---:|---:|---:|---:|
| 已接受基线 | 1,198,934 | 0 | 170 | 0.014341 |
| 自适应平滑 | 702,412 | 0 | 28 | 0.015059 |
| 中等低频平滑 | 338,390 | 0 | 24 | 0.015909 |

结论：适合主动减少几何细节、改善大面平顺的需求；仍有灯、电视轮廓变形，
不能作为全面优于基线的结论。零开放边不等于无自交、无误色或形状真实。
浏览器检查通过仅表示成功渲染且无运行错误，人工视觉检查仍发现缺陷。

更强的约 8.6 万面版本损伤薄物体，不作为推荐候选。图割分区和多视角
颜色离群拒绝也没有成为默认方案，原因和复现命令见
[算法及试验记录](../../docs/mesh-lowpass-and-patches.md)。
