# 几何引导平滑与原机位优先：验证记录

实现、算法边界和复现命令见 [说明](../../docs/geometry-guide-smoothing.md)。
本轮选择 `geometry-smooth-guide-photo-six-v1` 作为独立预览候选；全部旧
模型保留，没有将有局部退步的原机位加权模型替换成新的上游基线。

输入为已接受 `tour-appearance-six-v1` 的等价检查点，输出约 120 万面 Mesh，
重新投影六张 7680×3840 原片；相机数量和邻接关系从元数据读取。
`geometry-guide.ply` 为 499,223 个带法线的表面点，约 24 MB，不是高斯 PLY。

## 决策

- 深度强平滑：同 114 个视角，未命中射线 71,303 → 63,583，采用。
- 只使用原机位深度：115,111，覆盖退化，不采用。
- 当前虚拟深度支持过滤：88,543，覆盖退化，不作为默认。
- 原机位更高采样和损失权重：原机位小幅改善，但留出视角退步，不替换
  现有单一高斯。`anchor-evaluation.json` 和 `anchor-training.json` 留档。
- 自动平面强约束：局部异常面，保持独立试验，不选择为最终预览。
- 连续曲面重建再加三维点 / 法线平滑：主要平面附近法线起伏下降约
  13%–15%，支持面积相近。114 个方向无未命中射线，但仍有 170 条非流形边，
  不能把闭合率视作真实几何精度。

## 已验证

- 图像合成深度不等同于实测深度；平面也仅为拟合先验。
- 浏览器 18 个原机位方向、6 个中点、几何和照片分区模式；另 96 个斜视
  / 路线方向检查通过。实际查看地面、天花板、门和桌边，仍有灯、椅背及
  遮挡区的形变、误色与纹理接缝。
- 原始 / 中等 / 强平滑使用相同输入和重建参数；各阶段射线、拓扑、深度
  改变量及无贴图命中数均保留在 `*-audit.json`。
- 平滑点云经 Open3D 回读，数量、有限坐标与单位法线通过检查。
- 新预览标题及引导点云链接已用独立测试浏览器验证。
- 单元检查覆盖噪声平面、斜平面、断层与细条、未知深度、遮挡、点云法线、
  三维位移上限、相邻分离表面、原机位分类及旧高斯细分。
- 两份旧单一 PLY 哈希保持不变，见 `baseline-verification.json`。
