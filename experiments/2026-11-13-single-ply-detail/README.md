# 单一 PLY 细节蒸馏：独立候选，保留旧版

本轮实现与命令见 [算法说明](../../docs/single-ply-detail.md)。输出
`tour-detail-single-six-v2/final/fused.ply`，约 299 MB、1,967,420 个 SH2
高斯。原始模型、全景照片和生成图片不提交到公共仓库。

## 选择结果

旧 `tour-appearance-six-v1` 和 `tour-distilled-six-v3` 文件哈希未改变，
检查见 `baseline-verification.json`。旧算法默认参数不变；代码回退点为
`baseline-single-ply-before-detail-20261113`。本轮两个候选使用独立目录。

首轮增加高斯细分、较小且衰减的学习率、局部色度误差和较窄视场监督。
第二轮增加自动生成的交接附近训练/留出位置。同批 408 个方向，第二轮
平均及局部误差略好于首轮，选择第二轮为可下载的试验候选。

1024 检查包含 36 个原机位方向与 516 个未训练视点或方向。相对旧单一
模型，原机位 MAE 下降约 40.5%，留出检查 MAE 下降约 10.4%。
这是对合成参考的数值误差变化，不是清晰度的百分比提升。

严格保真门槛未通过。1–6 交接电视区域局部 P95 仍比旧版差，不能升级为
全局默认基线。同相机两份来源模型的轮廓/合成深度存在冲突，补采样未能
消除该退化。保留旧版本对照和原始漫游入口，不以平均指标代替局部验收。

## 验证与可视化

- 导出回读精确一致，文件只含一份模型，SH2 字段完整。
- 1280×1280 浏览器捕获 13 个方向，含 50° 和 90° 视场、上下方向和路线
  位置；网络只请求本次一个 PLY，未请求六份原始模型，无脚本异常。
- 实际浏览器截图已检查：仍有地面斑点、天花板细小斑点和局部软化，不能
  宣称达到原片高清。与同相机 GPU 渲染平均差为 0.004356（RGB 0–1），
  说明两渲染器仍有差别，离屏数值不可直接当成屏幕逐像素一致性证明。
- 报告中提供局部退化按钮，原始漫游对照显式使用 49% 范围，旧 PLY 和
  下载链接通过 HTTP 检查。
- 单元检查：机位/交接采样 4 项、细分与表面工具 5 项、局部色度指标 3 项。

公开数值文件包含训练记录、640/1024 汇总、局部最差方向、共同检查集选择、
PLY 校验、浏览器捕获检查、渲染差异与来源冲突诊断。图像对照保存在本机
预览服务的场景目录中。
